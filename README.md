# The Board

**Power, plainly.**

A twice-weekly briefing on geopolitics, money, and influence, written for one reader, by Josh Pilcher. New reports Tuesday and Friday evenings.

Read it live: **https://1pilcher.github.io/the-board/**

---

## What it is

The Board is a briefing on power: who has it, how it moves, and what it costs. Geopolitics, markets, the Fed, commodities, war, trade, elections. The forces that decide what happens next, explained in plain English with the history that makes them make sense.

Every report is built by a team of analysts working blind. Historians, power mappers, economists, localists, and red teams who hold veto power over any claim that doesn't survive scrutiny. What survives is what gets published.

## How to read

- **Latest** — the newest report, featured up top.
- **All** — every report, newest first. Each report keeps its own permanent address, so a new story never buries an old one.
- **Purpose** — why The Board exists, in the author's own words.

Each report opens with a plain-English bottom line, then the full story.

## Why The Board exists

> I don't have a ton of time. It's hard to keep up.
>
> There are so many conflicting narratives, fed by conflicting interests. It feels hard to know what is true, and I know I'm not alone in that.
>
> I often find that I have questions I'd like the answer to, or have things I don't understand that simply aren't covered by the news. Not all of the time but sometimes.
>
> My ideal world is that I build something that is beneficial to me. That I enjoy reading. Because if I do, so will other people and it will help them too.

## Structure

- `index.html` — the homepage (Latest, All, Purpose).
- `YYYY-MM-DD-<topic>/index.html` — each report in its own dated folder.

## Format

Every report is a standalone longform piece in the same design system: cream paper, near-black ink, a lighter red accent, PT Serif body text, and a visual in every section. Static pages, no animations, built to read beautifully on any screen, phone, laptop, or desktop.
