Sixteen treatments for the mark beside a section head. Each one runs on its own clock, whether you scroll or not. The tile under each is identical, so the only thing being judged is the mark. The second five lean on texture, the shade lines an engraver cuts by hand. One more is built from the name itself: a rank of the board, squares running to the margin, a single red pulse walking them. The last five drop the line entirely: a small working device opens the section instead, standing at the left of the section name and exactly as tall as the name itself.

Batch four: bands drawn for the band. The mark beside the name is as tall as the lettering itself, so these five were designed at that height from the first stroke — fields, stacks and traces whose native shape is the whole band, not a thin line made taller. Same fixed gap after the word, same flush run to the right margin.
