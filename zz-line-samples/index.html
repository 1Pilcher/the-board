Ten treatments for the line beside a section head. Each one runs on its own clock, whether you scroll or not. The tile under each is identical, so the only thing being judged is the line. The second five lean on texture, the shade lines an engraver cuts by hand.

Sample 1 · The Current

The Current

The headline under the line, at the size it will actually run

This tile is only here so the line gets judged where it will live, beside the section name and above the news, at the same weight and width it carries on the front page.

The line itself keeps its own time. Scroll or do not scroll; it runs either way.
